# Settings

Every setting ttheme reads, the values it takes and its default. This page is
made from the same source as the comments in your `config.zsh`.

Settings live in `~/.config/ttheme/config.zsh`. `ttheme config` opens it in
`$EDITOR`, and `alt+c` in `ttheme` edits the common ones in place. Each default
sits on a commented line, so a default a later version changes reaches you; a
line you uncomment keeps your value. A variable exported before ttheme loads
wins over the file.
