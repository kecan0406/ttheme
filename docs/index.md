# ttheme Docs

ttheme is a terminal theme tool and platform that puts your favorite
character's palette on your terminal. It supports many terminal emulators, stays
light, and anyone can use it with ease.

## Get Started

Install and run ttheme with one command! It works right away, with no setup.

```sh tab="npx"
npx ttheme@latest init
```

```sh tab="bunx"
bunx ttheme@latest init
```

[Get Started](guide/quickstart.md) walks through init, loading the command and
picking your first palette.
