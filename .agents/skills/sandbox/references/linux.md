# Linux terminals, on a private display

The window scripts are macOS's (`screencapture`, `lsappinfo`). On Linux, `mise run sandbox --behind` with `--konsole`, `--kitty`, `--alacritty`, `--wezterm`, `--warp`, `--rio`, `--contour` or none (Ghostty) starts that terminal from its binary on `PATH` on its own Xvfb display (`TTHEME_XVFB_DISPLAY`, `:77`), so nothing shows on the user's screen and a locked screen changes nothing. Konsole also gets its own D-Bus session (`dbus-run-session`), so `ttheme default` reaches only that Konsole over D-Bus and nothing touches the user's `konsolerc` or `~/.local/share/konsole`; it needs `konsole`, `dbus-run-session`, `Xvfb` and `xdotool`. Warp starts on the sandbox's `~/.config/warp-terminal` with its onboarding marked done (`user_preferences.json`: `HasCompletedOnboarding`), takes its shell from the account's login shell, not `SHELL`, and is refused while another Warp runs, since a second start opens its window in that one. `mise run compat konsole` and `mise run compat --linux` (Ghostty, `ghostty-tip`, kitty, Alacritty, WezTerm, Warp and Rio in `tests/compat/linux.Dockerfile`, and Contour, whose Linux build is amd64 alone, in `tests/compat/contour.Dockerfile`) drive them the same way inside a container and screenshot the window with `xdotool search --onlyvisible --pid` and ImageMagick's `import`; on macOS that is the way to measure them with no window at all. Measured on Konsole 23.08.5, 2026-09-28: a profile or scheme written after Konsole started is found by `setDefaultProfile` only when Konsole already lists it (`profileList`), so a first `init` needs a restart; an OSC 50 `ColorScheme=` repaints the tab with the scheme's 16 colors at once. On 2026-10-02: a scheme's wallpaper shows once `xcompmgr` runs on the display (23.08 draws one only on a translucent window, which it makes only under a compositor); a scheme a tab shows keeps what it was read as, a name no tab shows is read again, and a new name is read on demand — `mise run compat konsole` records these as the `scheme-*` cases.
