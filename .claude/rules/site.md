# site/

## Conventions

- The design system is the Design System artifact https://claude.ai/artifact/D3TtwiZtWyM175ydwyWCyv — read its README before styling anything. `app/globals.css` is its code form.
- `site/` consumes `@base-ui/react` only through `site/components/ui/*`, managed by the shadcn CLI (`site/components.json`, style `base-nova`, icons `lucide-react`): add parts with `bunx shadcn@latest add <name>` from `site/`, then adapt them in place — a part's looks are `cva` variants in its ui file, never a long `className` passed from a feature component, and feature components never import `@base-ui/react` directly (biome enforces it). Every part renders `data-slot` (and `data-variant`/`data-size`); ui parts carry no `dark:` variants — tokens do the theming.
- Tokens use shadcn's vocabulary plus `soft-foreground`, `faint-foreground`, `success`, `warning`, `overlay`, `glass`, `glass-panel`: `:root` is light, `.dark` is dark, and `<html>` gets `.dark` from the `theme-mode` script in `layout.tsx` (a stored choice from `ThemeToggle`, else `prefers-color-scheme`). Shadows go through `--elevation-*` so each theme has its own.
- Only the scale: text `2xs` 11 · `xs` 12 · `code` 12.5 · `sm` 13 · `base` 15 · `display-sm/md/lg` (fluid) and `display-xl` for the landing's hero only, radius from `--radius: 10px` (sm 6 · md 8 · lg 10 · xl 14 · 2xl 18 · 3xl 22), spacing on Tailwind's 4px steps. `text-[13.5px]`, `gap-[9px]`, `rounded-[3px]` are off the system; arbitrary values are for layout tracks, breakpoints and blur only.
- Faces: `font-sans` Inter for UI, `font-display` `Nunito` → `Hiragino Maru Gothic ProN` → `BIZ UDGothic` (Nunito and BIZ UDGothic loaded by `next/font`) for palette names, the wordmark and page titles at `font-black` (list rows `font-extrabold`), `font-mono` JetBrains Mono for commands, ids, hex values and terminals.
- Every page but the landing stays at this soft level and nothing louder: cards and the dialog `rounded-3xl` (22px), buttons `rounded-full`, inputs and command rows `rounded-lg`; neutrals carry a little of `primary`; `ease-spring` (a `linear()` spring with a `cubic-bezier` fallback) only on a card's `animate-enter` and press, never on hover; nav, labels and toggles lowercase; a kaomoji only in a passing state (`copied (・ω・)`, an empty result, no such market), one per view, never in a heading, doc or error.
- Routes: `/` the landing (`components/home.tsx`), `/sheets` a palette browser (`components/sheets.tsx`: the page wears the palette, a centered name with prev/next and ←/→, the tabbed TerminalWindow, a `ttheme use` row, a collapsible "slots and contrast" glass panel reusing the dialog's parts, and a sticky glass filmstrip of every palette grouped by series that keeps the current one centered; there is no picture/backdrop view any more), `/market` and `/market/store`. The landing is the one page allowed a louder layer on top, and only there: the `pop` Button (a 4px lip, one per page), the `sticker` Badge, `Sparkles` on the hero name, the dancing ANSI pills (`animate-dance`), `animate-squish` when the hero changes palette, color emoji on the feature cards, and `KaomojiRain` (type `uwu`). It cycles the series leads every 4s until a visitor picks one, never under reduced motion, and hides the theme toggle since the page wears the palette.
- `.wear` makes an element wear a palette: `wearStyle(theme)` (`lib/wear.ts`) sets the raw slots (`--bg`, `--fg`, `--cu`, `--se`, `--a0`–`--a15`) and the class remaps every token onto them. The landing, `/sheets` and `PaletteDialog` wear the current palette whole; cards and `TerminalPreview` set the slots only. The market chrome stays on the neutral tokens.
- `/market` (`app/market/page.tsx`, `components/market-gallery.tsx`) lists the official series, then a `── markets` line and each market, the CLI's order; a palette opens in `PaletteDialog` at `#<id>`. `/market/store?m=<owner@name>` is one market's page, picked on the client — a static export cannot build a dynamic route with no params, and there may be no markets. Markets come from GitHub's topic search for `ttheme-market` and each hit's `ttheme-market.json` at build time (`lib/markets.ts`, `GITHUB_TOKEN` when set, an empty list when the network is not there), so `pages.yml` rebuilds daily to pick up new markets.

## Gotchas

- `bunx shadcn@latest add` can emit `import { cn } from "cn"` and add the unrelated `cn` npm package to site/package.json — point the import at `@/lib/utils` and `bun remove cn`. It also stops at an overwrite prompt for an existing part: pipe `yes n` to keep ours.
- A page wrapper that is a `grid` needs `grid-cols-[minmax(0,1fr)]`, or a child's min-content (a nowrap command, an `auto-fit` grid) widens the track past a phone's width; a `<button>` used as a grid container needs it too.
- A `.wear` root that changes palette takes `useSettling(key)` (`lib/wear.ts`): for 650ms `data-settling` turns off every descendant's own transition, so text and borders follow the root's 0.6s palette fade exactly instead of chasing it. A TerminalPreview inside a worn page takes `worn` and inherits the slots rather than setting them, or it snaps while the page fades. `applyMode` likewise suppresses transitions for one frame when light/dark flips.
- `cn` (`lib/utils.ts`) extends tailwind-merge with the custom text sizes (`2xs`, `code`, `display-*`). Add any new `--text-*` there, or tailwind-merge takes it for a color and drops it when a `text-<color>` follows.
